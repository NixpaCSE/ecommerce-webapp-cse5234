# BobaBox – CSE 5234 E-commerce Web App

Group project for CSE 5234 (Distributed Enterprise Computing).

BobaBox is an online-only store that ships DIY boba kits (tea, syrups, and tapioca pearls) to customers' homes.

The React front end (presentation tier, Lab 5) lives in [`bobabox/`](bobabox/README.md).
